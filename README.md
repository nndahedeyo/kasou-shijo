# 仮想市場 試験所（Kasou Shijo）

暗号資産にくわしい人に向けた、値打ちのないテスト用のネットワーク（Base Sepolia）の上の試験所です。
「理想の取引所」の考え方を、本物のお金を使わずに試します。

- **資産を預からない。** 資産はいつも参加者のアカウントにあります
- **注文の条件だけに署名する。** 「Xを渡して、Y以上を、この時刻までに受け取る」
- **まとめて約定する。** 集まった注文を、全員同じ値段で約定させます（先回りの売買を防ぐ）
- **100年先の簡単さ。** 顔認証1回で開設、英単語なし、手数料は見えない、名前で送れる、鍵をなくしても信頼できる人の承認で戻せる

初心者向けの「仮想資産 練習所」とは別のものです。

### まとめて約定させる計算の約束

- 誰も、自分の注文の条件より不利な約定にならない
- 端数の計算で、資産が増えたり消えたりしない
- 約定する量が一番多い値段を選び、同じ量の値段が並ぶときはその真ん中にする（片方だけが得をしない）

`node --test "tests/*.test.js"` で確かめられます。ばらばらな注文2000通りでも、上の約束を守ることを毎回確かめています。


## アカウント（がまぐち・jeni のプロフィールカードにあたる部分）

相互レビュー・jeni・この試験所で共通に使えるように作っている、ひとつのアカウントです。

- **顔認証・指紋で開く：** パスキーの PRF という仕組みで、パスキーから毎回同じかぎを作り直します。英単語の控えはいりません。パスキーが同期される端末（同じ Apple アカウントや Google アカウント）なら、どの端末でも同じアカウントで開けます。パスキーが使えない端末では、かぎをその端末の中に置きます
- **ひとつのかぎから：** 出来事に署名するかぎ（Nostr）と、試験チェーン（Base Sepolia）のアドレスが、同じかぎから作られます
- **名前で探せる：** `@なまえ` は早い者勝ちで、1つのアカウントに1つです
- **プロフィールカード：** 表示名・ひとこと・リンクを、jeni のカードと同じ 1.586:1 の札で見せます
- **信頼できる人で取り戻す：** かぎをなくしたら、新しい端末で取り戻しを頼み、合言葉を信頼できる人に伝えます。決めた人数の承認がそろってから3日で切り替わり、そのあいだは今のかぎを持つ本人が取り消せます
- **運営なし：** 出来事は署名して中継（Nostr、種類 7720）に置き、だれの画面でも同じ決まり（`core/account.js`）で数え直します

まだしていないこと：かぎを盗まれたときに信頼できる人が止める仕組み、相互レビューのかぎをこのアカウントに切り替えること、試験チェーンでの実際の決済。

## 注意

テスト用のネットワークのトークンには値打ちがありません。売り買いもできません。本物の資産やリカバリーフレーズを、ここで使ったり入力したりしないでください。運営が鍵や英単語を聞くことはありません。
